# Туту — лендинг для Таджикистана

Готовая статическая версия сайта. Сборка не требуется.

## Как открыть на компьютере

1. Распакуйте архив.
2. Не отделяйте папку `assets` от файла `index.html`.
3. Откройте `index.html` в браузере.

## Как опубликовать на GitHub Pages

Загрузите `index.html`, `.nojekyll`, `README.md` и папку `assets` в корень репозитория, затем включите GitHub Pages для ветки `main` и папки `/ (root)`.

В этой версии есть адаптивная мобильная вёрстка, выбор языка и валюты, курсы валют, счётчик взрослых и детей, календарь, форма входа и компактный баннер отелей.
